## 구성
1. 한 달에 200마일
2. 나일강에 댐을 짓는데, 왜 바다 얘기를 꺼냈을까
3. 맨 앞의 유조선에 누가 탔나
4. 닷새 먼저 작성된 문서
5. 1파운드의 가격을 지키는 비용
6. 실제 통화 기록을 펼쳐 보면
7. 휴전 뒤, 약이 도착하기까지
8. 전쟁이 남긴 두 장의 종이
